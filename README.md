# Time Me

Time Me is a calm study timer for building focus, taking intentional breaks, and seeing your progress over time.

## Run it

Open index.html in a modern browser. There is no build step or dependency install. An internet connection loads DM Sans, Manrope, and DM Mono; system fonts are used if they are unavailable.

## Features

- Focus, short break, long break, and free-time modes
- Editable session lengths and optional automatic full-screen focus mode
- Timers pause when the page is hidden
- A study list with a selected next task
- Daily focus and free-time totals, a two-hour focus goal, and a seven-day focus chart
- Browser-local storage for settings, tasks, and session history; nothing is sent to a server

## Data

Time Me stores state in browser local storage. Clearing site data removes settings, tasks, and history. Full-screen depends on browser support and can be exited with Escape.
